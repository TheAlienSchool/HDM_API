Vocabulary Rename: Threshold → Prelude

Breaking rename All chamber files UX rationale

The Manual uses threshold as the primary term for the chamber entry overlay. Replace it globally with Prelude. This is not cosmetic — it changes the interaction model. A threshold implies crossing; a Prelude implies preparation at one's own pace. The user populations most valuable to this platform are those most likely to skip a threshold. A Prelude they can stay in.

Two additional terms enter the vocabulary: pace (each scholar's rhythm is honored — no timers, no prompts to move) and still point (the scholar's internal access point — they bring it; the Prelude does not manufacture it for them). The governing copy line for every Prelude: "Comprehension is not timed. It is simply available."

Pace Rules — Enforced in Code

These are not guidelines. They are constraints that prevent accidental violations during development.

  • No setTimeout prompts to move the scholar forward. If they are idle, they are steeping.
  • No progress indicators that show a percentage or step count within a chamber session.
  • Life Recipe text inputs: no minlength, no maxlength enforcement, no character counters.
  • Residue Test is a self-inquiry UI element — never auto-scored or auto-advanced.
  • sessionStorage timeout: none. A chamber opened and left for 20 minutes should restore its state exactly.

Three Code Additions

3.1 — Cross-Chamber Scholar Model (localStorage)
phi-ocean-shared.js State management

The Manual uses sessionStorage at the chamber level. This means accumulated scholar residue — the θ* across all eight encounters — resets between sessions. It also means Chamber 08's Pattern Completion engine has no scholar-specific data to surface. Replace with a persistent SCHOLAR module. By Chamber 03+, SCHOLAR.detectResonance() enables PING™ as UX (see §7.2).

// phi-ocean-shared.js — SCHOLAR module
// Persists the scholar's generative model across all chambers and sessions.

const SCHOLAR = (() => {
  const KEY = 'phi_scholar_v1';

  const defaults = () => ({
    visitedChambers: [],     // array preserves visit ORDER (braid)
    residue: {},             // { '01': { language, timestamp, visitCount } }
    stillPointMet: false,
    firstVisit: Date.now()
  });

  const load = () => {
    try {
      return JSON.parse(localStorage.getItem(KEY)) || defaults();
    } catch { return defaults(); }
  };

  const save = (state) => {
    try { localStorage.setItem(KEY, JSON.stringify(state)); }
    catch { /* storage full or blocked — degrade silently */ }
  };

  return {
    // Record completion of a chamber with the scholar's own language.
    record(chamberN, residueText) {
      const s = load();
      if (!s.visitedChambers.includes(chamberN)) {
        s.visitedChambers.push(chamberN);
      }
      const prev = s.residue[chamberN] || {};
      s.residue[chamberN] = {
        language:   residueText,
        timestamp:  Date.now(),
        visitCount: (prev.visitCount || 0) + 1
      };
      save(s);
    },

    // Returns prior language if scholar has completed this chamber before.
    priorLanguage(chamberN) {
      const r = load().residue[chamberN];
      return (r && r.visitCount > 0) ? r : null;
    },

    // PING detection: autonomous pattern recognition after 3+ chambers.
    detectResonance() {
      return load().visitedChambers.length >= 3;
    },

    // Braided history — the sequence, not just the set.
    visitSequence() { return load().visitedChambers; },

    clear() { localStorage.removeItem(KEY); }
  };
})();

Prelude integration: On Prelude init, call SCHOLAR.priorLanguage(chamberN). If a result exists, render the scholar's own text in IM Fell English italic beneath the formula display. They are met by their own prior knowing. On third+ visit, render first-visit date in DM Mono at 10px in the Prelude corner.

3.2 — φ-Timed Prelude Formula Reveal
phi-ocean-shared.js

The Manual specifies a "letter-by-letter reveal" for formula display in the Prelude but does not specify timing. Use φ-ratio intervals: each character arrives proportionally later than the previous. The animation enacts the formula before the scholar reads it. Add to phi-ocean-shared.js as a shared utility.

// φ-timed character reveal for Prelude formula display.
// Each character's delay = previous delay × φ, ceiling at MAX_MS.

PHI_OCEAN.revealFormula = function(element, formulaText, baseMs = 80) {
  const PHI = 1.6180339887;
  const MAX_MS = 420;

  // Respect reduced-motion preference.
  const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  if (reduced) { element.textContent = formulaText; return; }

  let cumulativeMs = 0;
  let interval = baseMs;

  [...formulaText].forEach((char) => {
    const span = document.createElement('span');
    span.textContent = char;
    span.style.cssText = `opacity:0; transition:opacity 0.38s ease ${cumulativeMs}ms`;
    element.appendChild(span);
    requestAnimationFrame(() => { span.style.opacity = '1'; });

    cumulativeMs += Math.min(Math.round(interval), MAX_MS);
    interval *= PHI;
    if (interval > MAX_MS) interval = baseMs; // reset at ceiling
  });
};
3.3 — iOS Safari AudioContext
phi-ocean-shared.js iOS critical

Known failure mode: iOS Safari requires a user gesture to unlock AudioContext AND frequently silences audio even after gesture-unlocking when the device is in silent mode. The Manual's sonic architecture (Part V) does not address this. It will surface at first iPhone test.

// Add to PHI_OCEAN shared utilities.
// Call initAudio() on any user gesture (tap, click) in the chamber.
// If audioReady remains false, show the visual-only fallback state.

PHI_OCEAN.audioReady = false;

PHI_OCEAN.initAudio = async function() {
  if (this.audioReady) return true;
  try {
    if (!this.ctx) {
      this.ctx = new (window.AudioContext || window.webkitAudioContext)();
    }
    if (this.ctx.state === 'suspended') {
      await this.ctx.resume();
    }
    this.audioReady = (this.ctx.state === 'running');
    return this.audioReady;
  } catch(e) {
    console.warn('AudioContext unavailable:', e);
    return false;
  }
};

PHI_OCEAN.showAudioStatus = function(indicatorId) {
  if (!this.audioReady) {
    const el = document.getElementById(indicatorId);
    if (el) {
      el.textContent = 'Touch anywhere to awaken sound';
      el.style.opacity = '1';
    }
  }
};

// Add a one-time gesture listener to each chamber page.
// Chamber 07 especially: audio is central, not supplemental.
document.addEventListener('pointerdown', () => {
  PHI_OCEAN.initAudio().then(ready => {
    if (ready) PHI_OCEAN.showAudioStatus('audio-status');
  });
}, { once: true });
